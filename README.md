# Ahmed Elsherif — Portfolio

A responsive, single-page portfolio built with plain HTML and CSS for GitHub Pages.

## Publish

1. Open the repository `ahmedelsherif-osama.github.io`.
2. Upload `index.html` and `style.css` to the repository root.
3. Commit the changes to the default branch.
4. In **Settings → Pages**, confirm deployment from the default branch and root folder.
5. Visit https://ahmedelsherif-osama.github.io/

## Before publishing

- Confirm that all live API demo URLs still work.
- Replace GitHub profile links on project cards with individual repository URLs when available.
- Confirm the Machine Learning Zoomcamp provider/course wording and current progress.
- Add any additional certificates only when their names and credentials are verified.
